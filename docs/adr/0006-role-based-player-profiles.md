# ADR-0006: 球员分析采用位置与角色画像，不以单一综合分为核心

- 状态：已接受
- 日期：2026-07-16

## 背景

初始设计把不同位置球员压缩为一个综合能力分，再聚合为球队实力。这种口径难以合理比较前锋、后腰、中卫和门将，也容易把长期能力、近期状态、出场负荷和样本量混在同一个数字中。

## 决策

1. 球员分析的主要产物是按位置和角色定义的多维画像，不是跨位置通用的单一综合能力分。
2. 画像至少区分出场时间与负荷、进攻、创造、推进、防守和门将表现；具体适用维度由球员角色决定。
3. 原始累计统计需要派生 `per 90`、同位置或同角色分位数，并在可行时进行赛事强度和对手强度修正。
4. 长期能力、近期状态、可用性和负荷是独立概念，必须分别保存和版本化，不能合成一个无法解释的“状态分”。
5. 每份球员画像必须带特征截止时间 `as_of`、统计窗口、样本分钟数、角色分类和指标定义版本。
6. 比赛预测模型消费版本化的底层维度特征。单一综合分可以作为界面摘要，但不得成为丢弃底层维度后的唯一模型输入。
7. 不同角色间不直接比较不适用的指标；缺失指标应显示为缺失或不适用，不能默认为零。

## 影响

- 球员数据模型需要区分原始单场观察、窗口聚合和角色画像。
- `per 90` 指标必须同时展示或携带样本分钟数，避免小样本极端值被解释为稳定能力。
- 指标、角色映射和基准人群变化时必须产生新版本，不能静默改写历史画像。
- 现有球员综合分可保留用于兼容，但需要逐步拆解其底层维度和使用场景。

## 未决问题

- 第一版角色分类体系和各角色必选指标。
- 长期能力与近期状态各自采用的时间窗口和最小分钟数。
- 联赛、杯赛和国家队数据的强度修正规则。
- 市场身价是否只作为外部验证信号，还是进入某些球员特征。
