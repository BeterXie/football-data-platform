# ADR-0007: 球队表现为基线，阵容与比赛上下文作为独立增量

- 状态：已接受
- 日期：2026-07-16

## 背景

初始设计用球员俱乐部数据解决国家队比赛样本稀疏问题，因此把球队实力主要建模为球员能力聚合。当前核心范围转向五大联赛后，球队拥有连续、丰富的逐场表现数据。若仍从球员分数重新构造全部球队实力，会丢失球队体系、教练、战术和长期配合信息。

## 决策

1. 五大联赛球队的长期实力基线来自球队级逐场表现，并按对手强度、比赛时间和必要的场地因素进行修正。
2. 球员角色画像不重新定义全部球队实力，而是根据预计或确认阵容，相对球队基线计算阵容增量。
3. `T-24h` 快照使用当时可知的预计阵容和可用性概率；`lineups-confirmed` 快照使用双方官方首发及可用替补信息。
4. 休息时间、赛程密度、伤停、停赛、场地、旅途和比赛目标属于独立比赛上下文层，并保留来源与调整审计。
5. 球队基线、阵容增量和上下文调整共同形成比赛模型的输入，最终用于估计双方进球期望和联合比分分布。
6. 同一事实只能在一个明确层级计价。已经通过阵容增量体现的缺阵，不得再以人工球队强度倍率重复调整。
7. 国家队或其他样本稀疏赛事可以提高球员先验的权重，但必须通过单独配置或模型版本表达，不能静默沿用俱乐部联赛权重。

## 影响

- 需要建立球队单场观察、滚动球队基线、阵容快照和上下文调整四类独立数据产物。
- 比赛预测应能够分别输出基线、阵容和上下文对最终进球期望的贡献，便于复盘。
- 赛后更新球队基线时使用比赛过程数据，不能直接把赛前新闻或市场赔率写回球队长期实力。
- 球员数据缺失会降低阵容增量的可信度，但不应抹掉已有球队基线。

## 未决问题

- 球队基线的第一版指标、时间衰减和对手强度修正方法。
- 预计阵容概率及替补贡献的计算方式。
- 球员缺阵、位置替代和战术变化如何映射到阵容增量。
- 不同上下文因素可以调整哪些模型参数及其幅度限制。
