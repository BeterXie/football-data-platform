# ADR-0022: Football-Data 仅作为赛程与赛果备用源

- 状态：已接受
- 日期：2026-07-16

## 背景

FBref 是第一阶段的主要球队和球员统计源，但当前公开赛程 URL 在本地运行环境返回
Cloudflare/HTTP 403 访问控制。访问控制不能被绕过，也不能被解释成零场比赛。
Football-Data 公开提供 2025-26 英超 CSV，包含完整赛程、90 分钟赛果和赔率字段。

## 决策

1. Football-Data 可用于补充赛事发现、球队名称、开赛时间和 90 分钟赛果。
2. 适配器只白名单读取 `Date`、`Time`、`HomeTeam`、`AwayTeam`、`FTHG`、`FTAG` 等赛程/赛果字段。
3. 同一 CSV 中的赔率字段全部忽略；它们不进入足球模型，也不自动成为正式市场基准。
4. FBref 继续承担主要球队过程统计和球员统计职责。Football-Data 回填通过不代表 FBref 逐场统计门禁通过。
5. 历史赛果的 `known_at` 暂按“开赛时间加三小时”重建，并显式记录策略版本；它不是实采时间。
6. Football-Data 名称身份与 FBref 来源 ID 必须通过显式来源映射合并，不能依靠名称在下游隐式关联。

## 影响

- 在 FBref 受限时仍可建立 20 队、380 场和真实赛果的 canonical 目录。
- 全部 raw CSV 和观察时间保留，刷新相同事实只增加证据关联，不复制 canonical 事实。
- 球队基线、球员画像和正式赛前快照仍会因 FBref/官方证据缺失而正确保持未就绪。
- 市场数据若后续启用，必须走独立 `MarketSnapshot` 适配器、时间门禁和真实基准评估。
