# ADR-0021: 新实现进入 `football-data-platform` 仓库

- 状态：已接受
- 日期：2026-07-16

## 背景

ADR-0020 决定在没有迁移计划时不原地重命名 `world-cup-predictor`，以免破坏其脚本、
历史数据和本地路径。当前已经存在一个独立、空白且由 Git 管理的
`football-data-platform` 工作区，适合承载新数据契约和英超纵向切片。旧仓库同时存在大量
世界杯、日报、赔率和未提交数据，继续直接重构会扩大污染与回归范围。

## 决策

1. `football-data-platform` 是新平台实现仓库和后续主开发位置。
2. `world-cup-predictor` 保留为历史仓库、解析回归样本和兼容入口，不进行原地重命名。
3. 权威设计、术语表和 ADR 迁入新仓库；后续架构决策在新仓库继续编号。
4. 只选择性迁移通用解析规则和经过验证的纯算法，不迁移世界杯编排、每日脚本、混合预测日志或历史生成数据。
5. 历史数据如需接入，必须通过显式版本化适配器进入新 `raw/canonical/derived` 契约，不直接复制成新口径。

## 影响

- ADR-0020 的“不破坏历史仓库”约束继续有效；其“当前仓库名”描述由本 ADR 更新为历史兼容语义。
- 新仓库可以使用准确的产品名和干净的 Python 包路径，无需保留世界杯业务分支。
- 两个仓库在过渡期并存；任何跨仓库迁移必须保留来源、时间和生成口径。
