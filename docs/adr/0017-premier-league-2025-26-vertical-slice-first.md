# ADR-0017: 先以 2025-26 英超完成端到端纵向切片

- 状态：已接受
- 日期：2026-07-16

## 背景

第一阶段最终需要覆盖五大联赛及 `2021-22` 以来的历史数据，但赛事身份、来源映射、快照、完整性资格和数据分层都是新契约。若先并行铺开全部赛事，设计错误会造成大规模重复返工。

## 决策

1. 第一条完整实施链选择 `2025-26` 英格兰足球超级联赛。
2. 纵向切片必须覆盖赛事注册、赛程与逐场 FBref 原始归档、规范实体、球队与球员事实、新闻事件、赛前快照、赛后生命周期、训练资格和静态报告。
3. 纵向切片需要证明 raw、canonical、derived 三层可以从采集到下游完整追溯，而不只是成功抓取一个页面或生成一份报告。
4. 英超特有信息通过赛事注册和来源配置表达。通过验收后，其他联赛与历史赛季必须复用同一编排和数据契约，不复制联赛专属脚本。
5. 该顺序不缩减第一阶段最终覆盖五大联赛与 `2021-22` 至今的范围。
6. 世界杯现有 FBref 归档可作为解析器和历史迁移参考，但不能替代英超纵向切片验收。

## 影响

- 优先暴露通用赛事发现、多赛季回填、身份解析和逐场统计中的真实问题。
- 其他赛事适配在核心契约稳定后以配置和少量来源适配器扩展。
- 纵向切片失败时先修复通用设计，不通过复制或特殊判断绕过。

## 未决问题

- 纵向切片的字段覆盖率、比赛覆盖率和失败率验收阈值。
- 历史赛前快照能够诚实重建的范围。
- 第一版静态数据质量与球员分析报告的具体版式。
