# ADR-0003: 首要比赛预测目标为赛前 90 分钟联合比分分布

- 状态：已接受
- 日期：2026-07-16

## 背景

训练数据必须先定义预测时点和预测目标。若特征没有明确的时间截点，赛后更新的伤停、阵容、新闻或统计可能泄漏进赛前训练样本。若不同盘口分别训练互不相干的概率，输出也可能自相矛盾。

## 决策

1. 首要比赛训练任务是在开赛前的明确时间截点，只使用该时点已经可知的数据，预测主队与客队的 90 分钟联合比分分布。
2. 90 分钟包含伤停补时，不包含加时赛和点球大战。
3. 胜平负、让球、总进球和准确比分等市场概率必须由同一个联合比分分布派生。
4. 每个训练样本必须关联比赛 ID、特征截止时间 `as_of`、不可变特征快照、90 分钟最终比分标签和数据版本。
5. 球员能力与球员单场表现使用独立的训练目标，不与比赛比分标签混为一个模型任务。
6. 每场比赛至少生成两份标准赛前快照：
   - `T-24h`：计划开赛时间前 24 小时生成的早期快照。
   - `lineups-confirmed`：双方官方首发均公布后生成的最终赛前快照。
7. 原始新闻、伤停、阵容和赔率可以持续更新，但训练、预测与评估必须引用具体的不可变快照，不能读取事后覆盖的当前状态。

## 影响

- 淘汰赛的晋级概率不是本训练目标，需要额外的加时赛与点球模型或显式规则。
- 盘口选择和 Kelly 计算属于价值投注模块，不属于比赛结果模型的训练目标。
- 具体模型可以变化，但所有模型必须遵守同一预测时点和输出契约。
- 训练集构建必须按事件时间过滤数据，不能用当前数据库状态回填历史赛前特征。

## 未决问题

- 比赛改期时 `T-24h` 快照的重建和保留规则。
- 市场赔率是模型输入、独立基准，还是两者分别建模。
- 联合比分分布采用何种模型族与校准方法。
