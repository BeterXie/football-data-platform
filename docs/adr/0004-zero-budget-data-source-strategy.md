# ADR-0004: 数据源预算为零并采用可追溯的尽力采集

- 状态：已接受
- 日期：2026-07-16

## 背景

第一阶段需要覆盖五大联赛、相关杯赛、欧战、国家队比赛、赛事新闻和球员级数据，并回填 `2021-22` 赛季至今的数据。项目没有付费数据源预算，因此无法依赖带完整性和可用性保证的商业体育数据 API。

## 决策

1. 数据源的月度预算上限为零，只使用允许访问的公开网页、免费 API、开放数据集和人工导入数据。
2. 采集器必须遵守来源的访问条款、访问频率限制和技术边界，不把绕过验证码、登录限制或其他访问控制作为正式方案。
3. 每次采集都保留不可变原始快照，并记录来源、原始标识、抓取时间、目标事件时间和解析器版本。
4. 来源适配器与规范化数据模型分离。任何单一网站的字段结构都不能成为平台内部数据契约。
5. 对赛程、比赛状态、最终比分和官方阵容等关键事实，在免费来源允许时采用多来源交叉验证。
6. 来源中断、字段缺失和来源冲突必须显式记录，不能把“没有抓到”解释为“事件没有发生”。
7. 零预算方案只承诺可观测、可恢复的尽力采集，不承诺商业数据服务级别的覆盖率、延迟或可用性 SLA。
8. FBref 是第一阶段的主要比赛与球员统计源，也是比赛报告原始快照的主要归档来源。
9. 复用现有 FBref 表格解析、原始快照和诊断能力，但把世界杯特化的赛事发现与运行编排改造成“赛事注册表 × 赛季”的通用采集流程；不得为每个联赛复制一套脚本。
10. FBref 不承担赛事新闻、伤停、停赛和官方首发快照。这些数据由独立的免费来源适配器采集，并通过统一比赛、球队和球员身份在时间版本层汇合。
11. 关键数据不完整时仍需归档、标记并继续补采，也可以生成明确标注的预览分析；但不得标记为 `training-ready`，不得产生正式价值投注建议。

## 影响

- 需要为每类数据维护来源优先级、备用来源和健康状态。
- 现有 FBref 世界杯逐场归档是可复用底座，不代表五大联赛、多赛季和上下文赛事已经覆盖。
- 需要补齐通用赛事注册、五年历史回填、逐场球队与球员统计，以及带 `observed_at/as_of` 的不可变快照。
- 历史回填深度受免费来源的可用性和授权边界限制。
- 数据记录必须携带完整性和可信度状态，供训练、预测和价值投注模块设置准入门槛。
- 新闻采集尤其可能存在缺口；系统必须保留原文证据和发布时间，不能只存自动摘要。

## 未决问题

- 关键字段来源冲突时的裁决和人工复核规则。
- 各类数据的目标更新频率和允许延迟。
- `training-ready` 对各类训练任务的具体必填字段。
