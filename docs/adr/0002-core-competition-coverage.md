# ADR-0002: 第一阶段核心赛事为欧洲五大联赛

- 状态：已接受
- 日期：2026-07-16

## 背景

数据平台需要明确第一阶段的核心赛事范围，避免采集、归档、训练和分析模块各自解释“主要联赛”。

## 决策

第一阶段必须完整覆盖以下五个男子顶级职业联赛：

1. 英格兰足球超级联赛（Premier League）
2. 德国足球甲级联赛（Bundesliga）
3. 西班牙足球甲级联赛（LaLiga）
4. 意大利足球甲级联赛（Serie A）
5. 法国足球甲级联赛（Ligue 1）

赛事身份应由稳定的赛事 ID 和赛季共同确定，中文或英文名称只用于展示，不作为唯一关联键。

同时建立上下文赛事范围，至少拉取赛程和球员出场数据：

- 欧洲冠军联赛（UEFA Champions League）
- 欧洲足联欧洲联赛（UEFA Europa League）
- 欧洲足联协会联赛（UEFA Conference League）
- 五大联赛球队参加的国内杯赛
- 五大联赛注册球员参加的国家队比赛

上下文赛事数据用于计算球员负荷、休息时间、伤停影响和近期状态。核心目标赛事与上下文赛事使用相同的球队、球员和比赛身份体系。

首批历史数据回填范围为 `2021-22` 赛季至今。原始数据永久归档；模型训练实际采用的滚动时间窗口由模型设计另行决定。

## 影响

- 五个联赛采用同一套比赛、球队、球员和赛季数据契约。
- 数据采集不能只按联赛过滤；必须追踪核心球队和球员在上下文赛事中的活动。
- “覆盖”所要求的字段完整性和更新频率仍需另行定义。
- 上下文赛事是否需要与核心赛事相同深度的事件和赛后技术数据，仍需另行定义。
