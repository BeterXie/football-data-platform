# ADR-0014: 训练准入按任务分别认证

- 状态：已接受
- 日期：2026-07-16

## 背景

比分模型、球队基线和球员画像需要的数据不同。缺少传球或防守明细的比赛仍可能具有可靠赛前快照和最终比分，能够训练比分模型；反过来，只有赛后球员统计而缺少正确赛前快照，也不能用于赛前预测训练。单一 `training-ready` 布尔值无法表达这些差异。

## 决策

1. `training-ready` 是一个资格集合，而不是全局布尔值。
2. 第一阶段至少定义以下训练资格：
   - `score-model-ready`
   - `team-baseline-ready`
   - `player-profile-ready`
3. `score-model-ready` 至少要求不可变赛前特征快照、明确 `as_of`、正确的 90 分钟比分标签、身份一致性和防泄漏校验。
4. `team-baseline-ready` 要求可靠的比赛结果和该版本球队基线规范规定的球队级过程数据。
5. `player-profile-ready` 要求可靠的实际阵容、球员身份、出场时间或角色，以及对应画像版本规定的球员统计。
6. 每项资格由独立、带版本的完整性配置和校验器计算，并记录未通过原因。
7. 同一场比赛可以通过部分资格而未通过其他资格；任何下游训练任务只能读取自己要求的资格版本。
8. 缺失值处理策略必须写入具体特征或模型契约。不得仅为了通过资格校验而静默填零或使用事后数据补齐赛前特征。
9. 每个训练数据集保存样本清单、资格配置版本、特征版本、标签版本和排除原因摘要。

## 影响

- 比赛生命周期中的 `training-ready` 表示至少一个训练资格已经通过，具体资格必须单独查询。
- 数据质量改进可以只提升受影响的训练任务，不必等待所有数据类别齐全。
- 模型评估报告必须说明训练和测试样本采用的资格配置。

## 未决问题

- 三项资格的第一版完整必填字段。
- 球队或球员高级指标不可用时允许的降级配置。
- 资格配置升级后是否以及何时重新认证历史数据。
