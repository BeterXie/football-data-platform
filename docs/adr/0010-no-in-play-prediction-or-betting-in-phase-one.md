# ADR-0010: 第一阶段不提供滚球预测或滚球投注

- 状态：已接受
- 日期：2026-07-16

## 背景

旧仓库包含实时比赛监控和滚球 Kelly 代码，但滚球系统需要低延迟事件流、当前比分与比赛时钟校正、红牌和换人状态、实时赔率、暂停与结算规则以及独立风险控制。它与已经确定的两个赛前快照不是同一个产品契约。

## 决策

1. 第一阶段正式预测和价值投注只基于 `T-24h` 与 `lineups-confirmed` 两类赛前快照。
2. 第一阶段不生成比赛进行中的实时胜率、盘口概率或滚球投注建议。
3. 比赛进行中的事件可以按免费来源能力采集，最终用于赛后归档、过程复盘和未来训练数据准备，但不承诺实时延迟 SLA。
4. 实时赔率不进入第一阶段正式价值投注流程。
5. 现有实时投注文档和代码视为遗留或实验能力，不代表当前平台的正式范围。
6. 未来若恢复滚球能力，必须单独定义事件时间、状态一致性、延迟、暂停条件、结算、模型和风险控制，不得直接复用赛前模型口径。

## 影响

- 第一阶段可以优先解决历史回填、赛前快照、赛后完整性和训练闭环。
- 采集到的进行中事件允许延迟到达或赛后补齐，不影响正式赛前预测 SLA。
- 用户界面和报告不得把赛前概率在开赛后继续展示为当前实时概率。
