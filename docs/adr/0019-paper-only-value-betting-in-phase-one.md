# ADR-0019: 第一阶段价值投注仅限纸面分析与模拟结算

- 状态：已接受
- 日期：2026-07-16

## 背景

价值投注模块依赖模型概率、真实市场快照、结算规则和风险控制。当前历史校准样本有限，新的前瞻 `captured` 快照尚需持续积累，而且数据平台与评估闭环正在重构。直接连接真钱账户会把模型和数据不确定性转化为不可逆损失。

## 决策

1. 第一阶段价值投注模块只生成市场候选、概率与价格分析、风险过滤结果和纸面仓位建议。
2. 第一阶段维护不可变纸面投注账本，记录预测快照、赔率快照、规则版本、建议仓位、实际赛果和按真实规则计算的结算。
3. 第一阶段不连接博彩账户、支付工具或自动下单接口，不保存用于自动投注的账户凭据。
4. 报告必须明确标记“纸面模拟”或“研究用途”，不得把候选列表描述为已经验证可投入真钱的策略。
5. 纸面 ROI、命中率和短期资金曲线仅用于运营诊断，不能替代概率评分、市场基准和校准检验成为模型晋级依据。
6. 启用真钱前必须另建 ADR，至少审查前瞻 `captured` 样本规模、时间外市场基准、模型稳定性、同场相关风险、总敞口、结算准确性和适用法律或平台规则。
7. 未达到正式模型晋级和价值模块准入条件时，可以继续影子运行和积累样本，不得通过放宽数据质量门槛制造更多投注记录。

## 影响

- 当前每日投注输出需要在展示和数据字段中明确区分研究候选与正式权限。
- Kelly 仓位只是纸面风险模拟输入，不代表系统授权实际下注。
- 纸面账本必须使用当时真实可得的赔率，不能使用赛后最佳价或合成赔率。

## 未决问题

- 纸面账本的市场覆盖、结算来源和复核流程。
- 真钱评审所需的最低前瞻样本和观察周期。
- 价值模块的同场、单日和跨市场风险配置版本。
