# ADR-0011: 整届赛事模拟是可选下游应用

- 状态：已接受
- 日期：2026-07-16

## 背景

初始设计把世界杯冠军与晋级概率模拟列为四个核心阶段之一。当前系统的首要目标已经转向多赛事数据平台、赛前单场概率、球员分析和独立价值投注。若继续让赛事模拟决定上游架构，会分散历史回填、数据质量和训练闭环的优先级。

## 决策

1. 世界杯冠军、阶段晋级概率以及未来可能的联赛赛季模拟保留为可选下游应用。
2. 整届赛事模拟不属于第一阶段数据平台的完成标准，也不阻断数据采集、训练或赛前预测交付。
3. 模拟器必须消费正式版本的单场联合比分分布和统一赛事结构数据，不得维护另一套隐式球队强度或比赛概率。
4. 90 分钟赛果概率与最终晋级概率保持分离。加时赛、点球大战和赛事晋级规则必须作为独立模型或显式模拟假设记录。
5. 在基础数据与单场模型通过验证前，赛事模拟结果只能作为实验输出，不得用于证明模型具备投注优势。
6. 现有赛事模拟代码可以保留兼容，但其硬编码赛制、平局决胜规则和数据入口需要在未来升级时单独审计。

## 影响

- 第一阶段资源优先投入通用赛事数据、球员与球队特征、赛前快照和评估闭环。
- 模拟模块可以独立迭代或暂停，不影响核心数据平台。
- 新增赛事模拟时必须提供赛制版本和假设说明，不能只输出冠军概率。
