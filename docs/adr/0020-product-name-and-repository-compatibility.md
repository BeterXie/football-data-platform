# ADR-0020: 产品命名为足球数据与预测平台

- 状态：已接受
- 日期：2026-07-16

## 背景

`world-cup-predictor` 最初描述世界杯单场与整届赛事预测。当前目标已经扩展为五大联赛及相关赛事的数据采集、归档、球员分析、训练、赛前预测和独立价值投注模块，原名称不再准确。

## 决策

1. 当前产品名称为“足球数据与预测平台”，英文短名为 `football-data-platform`。
2. 新的权威设计文档和领域文档使用新产品名称。
3. 现有仓库目录和代码路径暂时保留 `world-cup-predictor`，避免在架构迁移前破坏脚本、数据路径和本地环境。
4. 旧名称只作为历史仓库名和兼容标识，不再定义产品范围。
5. 将来是否重命名仓库、Python 包和数据根目录，需要单独迁移计划，不与当前设计对齐工作捆绑。

## 影响

- 文档必须区分产品名称与当前仓库路径。
- 新代码不得因为历史仓库名继续硬编码世界杯业务边界。
- 仓库重命名前，外部命令和文件链接仍使用现有路径。
