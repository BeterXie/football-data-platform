# ADR-0018: 严格区分实采快照与历史重建快照

- 状态：已接受
- 日期：2026-07-16

## 背景

平台将在 2026 年以后真实封存 `T-24h` 和官方首发后的赛前信息，但回填 `2021-22` 以来的历史比赛时，当前网页或赛后数据库不能证明某条信息在当时的赛前时点已经可见。把事后可见状态伪装为历史赛前快照会造成严重时间穿越。

## 决策

1. 所有赛前快照必须记录 `capture_mode`，至少区分 `captured` 与 `reconstructed`。
2. `captured` 表示平台确实在比赛开始前采集、封存并记录了 `observed_at` 的不可变快照。
3. `reconstructed` 表示比赛结束后，根据具有可靠事件时间或发布时间的历史事实构建的研究快照。
4. 重建快照只能包含能够证明在目标 `as_of` 之前已经发生或公开的信息。无法证明当时可知的字段保持缺失，不能用当前状态或赛后报道补齐。
5. `captured` 与 `reconstructed` 样本不得在评估报告中无标记混合。所有指标必须按快照来源分层展示。
6. 正式模型晋级主要依据前瞻 `captured` 快照的时间外表现。`reconstructed` 数据可以用于预训练、特征研究或受限回测，但不能单独证明生产效果。
7. 若某项历史事实虽在赛前发生，但来源只提供赛后更新时间且无法确认首次公开时间，该事实不得进入对应重建快照。
8. 快照重建规则必须版本化，并为每个字段保留来源事件时间、抓取时间和纳入理由。

## 影响

- 历史回填可以先建立可靠的赛后和长期基线数据，但完整赛前证据需要从现在开始持续积累。
- 历史模型样本量可能因严格时间证据而下降，这是避免泄漏的必要代价。
- 报告和训练清单需要展示各类快照数量、缺失率和来源构成。
- 比赛改期时，每份实采快照仍保留其当时计划开赛时间与真实 `observed_at`。

## 未决问题

- 各免费来源可以信任的首次发布时间字段。
- 历史官方首发和赔率快照的可重建来源范围。
- 模型晋级时 `captured` 样本的最低数量和观察周期。
